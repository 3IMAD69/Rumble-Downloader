# Rumble Video Downloader

## Descripción General

Este proyecto es un descargador de videos de Rumble que simplifica el proceso de descarga de videos de la plataforma. Con esta herramienta, los usuarios pueden descargar videos de Rumble fácilmente simplemente pegando el enlace del video. La aplicación se encarga del resto, brindando a los usuarios diversas opciones de descarga en alta calidad.

## Características

- **Descarga Fácil**: Simplemente pega el enlace del video de Rumble y obtén acceso a las opciones de descarga.
- **Alta Calidad**: Descarga videos en alta calidad con facilidad.

## Tecnologías Utilizadas

- **Next.js**: Utilizado para el renderizado del lado del servidor y para crear una experiencia de usuario fluida.
- **React**: Utilizado para construir la interfaz frontal y gestionar el estado de la aplicación.
- **Tailwind CSS**: Empleado para el diseño de la interfaz de usuario y para garantizar la adaptabilidad (responsividad).
- **Next.js Server Action**: Aprovechando el potencial de Next.js, la aplicación utiliza server actions para omitir el CORS y lograr una experiencia de usuario optimizada.

## Primeros Pasos

Para comenzar a usar el Rumble Video Downloader, simplemente sigue estos pasos:

1. Clona el repositorio en tu máquina local.
2. Instala las dependencias usando `npm install`.
3. Ejecuta el servidor de desarrollo usando `npm run dev`.
4. Accede a la aplicación en tu navegador web en `http://localhost:3000`.
5. Pega el enlace del video de Rumble en el campo de entrada proporcionado e inicia la descarga.
